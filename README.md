Students Database CRUD Application (EWB Internship Project)
A robust backend project built using FastAPI and SQLite for managing student records, complete with an optional local AI extension powered by Ollama[cite: 1]. Developed for the EWB Edu Tech Pvt. Ltd. Python Backend Development Internship[cite: 1].

Features
Create: Add new student profiles with validation[cite: 1].
Read: List all students, view individual profiles, or filter by course and date of birth[cite: 1, 2].
Update: Modify specific student properties dynamically[cite: 1].
Delete: Remove student records securely[cite: 1].
Optional AI Extension: Query your database using natural language via local Ollama models (llama3.2:1b).
Prerequisites
Python 3.8+ installed on your system.
[Optional] Ollama installed locally if you want to test the AI endpoint.
